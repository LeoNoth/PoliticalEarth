PoliticalEarth — тест UI без изменения номера версии.

Изменения:
1. Постоянные строки характеристик из UI_stable_test (стиль и числовые поля не пересоздаются).
2. Выбор рот пересоздаётся только при изменении категории/ячейки/разрешённых вариантов.
3. Оформление 20 ячеек не пересоздаёт StyleBoxFlat при каждом изменении шаблона.
4. Статичные флаг, заголовок страны и дата не переназначаются при неизменных значениях.

Движок Godot 4.7.2 в рабочем окружении отсутствует. Выполнены проверки структуры исходников и ресурсов, не полноценный запуск.

Проверка на Android:
1. Открой проект и конструктор дивизий, несколько раз замени роты.
2. Открой правительство и переключи вкладки.
3. Запусти 2–3 игровых месяца, затем скопируй диагностический отчёт.
4. Сравни показатели «Интерфейс: конструктор», «Интерфейс: правительство», «Интерфейс: общий» и число кадров >50 мс.
Если проект не открывается или есть ошибка GDScript — вернись к архиву v0.1.33 и пришли строку ошибки.
